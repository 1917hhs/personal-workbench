# 个人工作台

一个本地优先的桌面工作台（Electron + React），面向同时跟多个项目、负责采购与多专业询价的工程项目负责人：项目文件以思维导图展开，配合项目信息、待办、通讯录与供应商库、询价比价、资料库和备忘录；也能让 AI 助手通过 MCP 读写这些数据。

本地优先：项目文件留在原来的位置，软件只记录结构之外的信息（备注、颜色、待办、项目信息等），全部是 JSON 文件，方便自己手动同步到网盘。

## 运行

需要 Node.js。第一次使用先安装依赖：

```
npm install
```

然后：

- `npm run dev` 或双击 `dev.cmd`：开发模式，改代码后界面自动刷新
- 双击 `start.cmd`：构建并运行

> 如果源码所在路径里有 `&`，Windows 下 `npm run xxx` 会报错，这时用上面两个 `.cmd` 脚本（它们直接调用 node）。

## 功能

| 模块 | 说明 |
| --- | --- |
| 工作台 | 统计卡（含供应商资质到期提醒）、待办、30 天日程（含已逾期未完成）、月历、项目列表、采购概况（询价进度 / 价格 / 供应商）、备忘录、便签、番茄钟统计 |
| 项目 | 卡片 / 列表 / 看板视图；卡片显示阶段、状态、委托单位、地点、待办与询价数量、阶段进度、负责人；支持子项目 |
| 项目导图 | 项目文件夹以左到右的导图展开；点阵背景，拖动平移、滚轮缩放，右下角缩略图可拖动定位；按文档 / 表格 / PDF / 图纸 / 图片 / 视频筛选；备注、着色、版本归组、引用（一个文件挂在多个位置不复制）；从资源管理器拖入归档，把节点拖出去发给别人 |
| 项目详情 | 项目信息、经纬度（可直接粘贴坐标定位）、子项目、待办、项目联系人及角色 |
| 预览 | PDF、图片、视频、Word（docx）、Excel、文本、CSV、Markdown |
| 地图 | 项目按经纬度标在地图上，颜色代表阶段；可画范围线；默认底图不需要 Key，国内可改用天地图 |
| 待办 | 按已逾期 / 今天 / 本周 / 以后 / 未安排分组，关联项目、星标；可设每天 / 工作日 / 每周 / 每月重复，完成后自动排下一次；删除后可撤销 |
| 供应商与联系人 | 联系人按单位归类；附件存在「供应商与联系人」文件夹下，每个单位一个子文件夹；单位 / 供应商库含类别、专业、服务国家、入库状态、等级、评分、入库资料与到期提醒、项目经验；选单位时可输入搜索 |
| 询价 | 一个项目的一个专业包为一条询价：询价文件按版次管理，发包记录，多轮回价（含税 / 不含税、税率、有效期、付款条件、范围、核实状态与疑点），比价表（最低价、比控制价、已过期），定标，导出比价 Excel；文件拖入即存到项目文件夹；删除时文件移到回收站 |
| 资料库 | 规范标准、模板、数据、影像等跨项目资料；自动识别规范编号，可标已废止及替代版本 |
| 备忘录 | 按时间分组的列表 + 直接编辑；可插入图片（可粘贴截图）、录音（可本机离线转文字）、视频、附件，引用资料库或项目文件（只记位置），被引用的文件删除、改名时会提示或自动更新；历史版本、回收站 |
| 工作流程 | 把公司审批流程画成流程图：步骤、分组框、标题栏、带条件的连线；每一步和每段连线可记审批人（可从通讯录选，显示电话）、所需附件（是否必交，可引用资料库里的模板）、时限、注意事项；「步骤清单」按顺序列出每一步找谁、交什么，可复制成文字；全局搜索和 AI 助手都能查。自带「采购管理」示例 |
| 番茄钟 | 可关联项目和待办，按今天 / 本周、按项目统计 |
| AI 接入（MCP） | 在本机开一个 MCP 服务（Streamable HTTP，仅 127.0.0.1，需令牌）。AI 助手可以查项目、读文件、搜索；「可读写」时还能整理文件夹、生成 Excel / Word、写备忘录、加待办、录入单位 / 联系人 / 询价 / 回价。每次修改都有记录，可撤销。AI 先读「AI 用户档案」了解用户习惯，录入回价参照 `docs/AI-采购录入指南.md` |
| 备份与分享 | 按类别把数据导出到「备份」文件夹或 U 盘，可加密（AES-256-GCM），在另一台电脑导入 |
| 设置 | 项目阶段、状态、成员、目录模板、文件隐藏规则、颜色含义、外观、单位与供应商的选项列表、存储位置等 |

## 数据存在哪里

第一次运行时选一个根目录（设置 → 存储位置 里可以整体搬家），下面分为：

- `数据\`：所有 JSON 数据
  - `projects.json` 项目，`meta\<项目id>.json` 导图节点的备注、颜色、折叠、引用
  - `todos.json` 待办，`stickies.json` 便签，`focus.json` 番茄钟记录
  - `contacts.json` 联系人，`companies.json` 单位与供应商，`inquiries.json` 询价
  - `library.json` 资料库目录
  - 语音识别模型默认在软件安装目录的 `asr-models\`（设置 → 语音识别 里安装、选用、改位置；升级时保留）
  - `kb\pages\` 备忘录，`kb\history\` 历史版本，`kb\media\` 备忘录里的图片、录音、视频、附件
  - `profile.json` AI 用户档案，`ai-log.json` AI 操作记录，`ai-backup\` AI 覆盖文件前的备份
  - `settings.json` 设置
- `资料库\`：资料库文件本身
- `项目\`：新建项目时创建的项目文件夹
- `供应商与联系人\`：单位的入库资料、项目经验附件
- `备份\`：「备份与分享」导出的数据包

写入时都先写临时文件再改名，网盘同步不会传到写了一半的文件；某个数据文件损坏读不出来时，会先另存一份再提醒。软件只允许同时开一个。

## 代码结构

- `src/main/`：Electron 主进程（数据存取、文件扫描与操作、预览转换、采购、备忘录媒体与引用、MCP 服务）
- `src/preload/`：给界面暴露的接口
- `src/renderer/`：界面（React）
- `docs/`：给 AI 助手看的录入指南
- `scripts/push.ps1`：用 GitHub CLI 的登录令牌推送（见下文）

## 推送到 GitHub

如果 git 的凭据助手不能正常工作，可以用 `push.cmd`（或 `powershell -ExecutionPolicy Bypass -File scripts\push.ps1`，加 `--dry-run` 只检查）。脚本每次从 `gh auth token` 取令牌，只用于这一次推送，不保存。前提是已运行 `gh auth login`。

## 打包成安装程序

```
node node_modules/electron-vite/bin/electron-vite.js build
node node_modules/electron-builder/cli.js --win nsis --x64
```

安装包输出到 `release/`。国内网络可先设置 `ELECTRON_MIRROR` 和 `ELECTRON_BUILDER_BINARIES_MIRROR` 为 npmmirror 镜像。
